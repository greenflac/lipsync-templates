## 1. Клип с полным обрывом в конце объявляется статикой. ВОСПРОИЗВЕДЕНО

Вход: 11 одинаковых кадров (значение 20) и двенадцатый кадр значения 230,
то есть скачок на 210 из 255 — полный обрыв картинки в конце.

    loop_seam:       ratio None | seam 210.0 | typical_step 0.0
                     seamless False
                     note: "the clip does not move at all."
    motion_quality:  moving False | smooth False | activity 0.0
                     note: "static clip: nothing moves."

**Почему это дефект.** В ОДНОМ словаре стоят `seam: 210.0` и «клип не
двигается вообще». Оба прибора отвечают «статика» о клипе, который в конце
меняется целиком. Причина видна в коде: медианный шаг между соседними кадрами
равен нулю (десять пар одинаковы, одна — нет), и обе функции по нулевому
медианному шагу уходят в раннюю ветку «ничего не движется», не посмотрев на
то, что уже посчитали.

**Чем это стоит продукту.** Это ровно тот класс, против которого написан весь
пакет: прибор отвечает УВЕРЕННО И НЕВЕРНО. Клип с обрывом — брак, который
заказчик увидит с первого взгляда, а два прибора подряд назовут его
неподвижным, то есть «просто скучным».

**Что я НЕ делаю.** Не правлю: файл заморожен. Правка выглядит маленькой
(нулевой медианный шаг — это не «нет движения», а «движение сосредоточено в
одном месте»), и именно поэтому решение о ней должно быть вашим, а не моим.

## 3. Три константы-решения без происхождения и без единого сторожа. ПОДТВЕРЖДЕНО

    SEAMLESS_MAX = 0.30
    JUMP_MAX     = 4.0
    STILL_MIN    = 0.15

Проверено командами:

* `grep -rn "SEAMLESS_MAX\|JUMP_MAX\|STILL_MIN" --include=*.py .` — вне самого
  модуля единственное упоминание `lipsync/fork_looper.py:48`,
  `CUT_JUMP = motion.JUMP_MAX`, то есть константа решает, ГДЕ РЕЗАТЬ клип;
* `grep -rn "loop_seam\|motion_quality" lipsync/tests/*.py` — ноль совпадений:
  ни одного теста;
* `python scripts/check_mutants_cover.py --check` — «БЕЗ МУТАНТОВ 3
  констант(ы)-решения: lipsync/motion.py».

**Почему это дефект.** По И4 у каждой константы-решения должно быть
происхождение: `ИЗМЕРЕНО` (чем, на чём), `РАСЧЁТ` (по докам) или `ВЫБРАНО`
(кем, из чего). Здесь нет ни пометки, ни теста, ни мутанта — значит поменять
0.30 на 0.60 может кто угодно, и ни один прибор проекта этого не заметит.
Это же три из девяти оставшихся непокрытых модулей ратчета R7: пока
`lipsync/**` заморожен, R7 ниже девяти не опустится.
