1. references/ and the collected prompt wording — from a third party's gallery

The records under references/ are derived from the curated public gallery at
aidsgn.ru. That gallery is somebody else's work and this project holds no
rights in it.

No image from that site is stored here. Each record holds derivatives: the
picture's palette described in this project's own colour vocabulary, a
wordless skeleton of the prompt's structure (word count, clause count, aspect
ratio, style flags), a SHA-256 of the image the record was read from, and the
URL that image is served from. The URL is a pointer rather than a copy — it is
there so somebody holding only the records can re-fetch the picture and check
the digest against it. Each record also carries the gallery section it was
filed under and the model marker the source printed beside it; both are labels
rather than content, and both are kept because a grouping somebody else made
is the only reason the measurements over this corpus are not circular.

Since 2026-08-25 the prompt wording itself is also collected, by a decision of
this repository's owner taken with the licence question in view. That reverses
the original position, which was to keep no wording at all. Every collected
row carries its own origin fields — `provenance` and `rights` — so the
material stays identifiable wherever the file travels, and so an exact removal
is possible if the gallery's owner asks for one.

This remains derived data assembled from somebody else's catalogue, not a work
of this project. This project grants no licence over it, because it has none
to grant, and asserts no rights of its own over the gallery it describes.
Anyone wanting the underlying images should get them from aidsgn.ru on
whatever terms that site sets.
