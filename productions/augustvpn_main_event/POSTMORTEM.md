# Постмортем: MAIN EVENT — АвгустVPN против Free VPN

Черновик. Обновляется по ходу производства. Источник правды — `journal.jsonl`
рядом с этим файлом. Здесь собраны выводы, числа берутся из журнала:

```bash
python -m studio.shoot journal productions/augustvpn_main_event/production.json
```

Цель документа — собрать из одного ролика пайплайн под **массовый контент**:
сколько стоит годный план, где теряются попытки и какие ошибки уже стали
правилами в коде, а какие ещё держатся только на внимательности.

## 1. Как этот ролик снимается сейчас

| Шаг | Где в коде | Что гарантирует |
|---|---|---|
| Сценарий как данные | `production.json`, `studio/shoot/spec.py` | один план — одна генерация; сторона экрана и взгляд — поля |
| Проверка до рендера | `python -m studio.shoot validate` | нет склеек внутри генерации, «голого» наезда, слов о блеске кожи, брендов, насилия, прыжков через ось |
| Промпт | `studio/shoot/compile.py` | схема разделов вендора MiniMax H3, пост камеры с оператором, рост числами, образ дома, реф канваса |
| Рендер | `python -m studio.shoot render` | preflight весов, бюджет, запись попытки в журнал (сид, хеш промпта, GPU-с, $) |
| Проверка после рендера | `studio/shoot/qa.py` | дрожь и зум камеры по посту, склейки, звук, OCR, контактный лист для глаз |
| Журнал | `studio/shoot/journal.py` | ни одно замечание владельца не остаётся без разбора и правила |

## 4. Ошибки → правила

У каждой строки есть инцидент в журнале (`kind: incident`) с полем `rule`.

| Симптом (кто заметил) | Причина | Правило |
|---|---|---|
| клипы без мира: нет окружения, света, камеры (владелец) | стек «картинка → анимация» | видеомодель со звуком и рефами; план = кадр трансляции |
| UFC/ESPN на перчатках и сетке (агент) | бренды из знаний модели о MMA | своя лига + рефы; `validate.BRANDS`; OCR в `qa.brand_hits` |
| звук «глючит» (владелец) | CUT внутри генерации | `validate.CUT_WORDS`, `qa.cuts`, «one continuous take» |
| блеск и бугры на коже (владелец) | слова промпта + жирный реф | `validate.SKIN_WORDS`, матовая кожа в образе дома, realism-LoRA выкл. |
| нереалистичная камера (владелец) | промпт про движение, а не про оператора | `camera.RIGS`, `validate` operator/bare_push, `qa` дрожь/зум |
| «UFC» на канвасе (агент, глазами) | запрет словами не держит пол | `spec.SetRef` — реф декорации |
| перчатка на конферансье (агент) | правило образа для всех планов | перчатки — только при бойце в кадре |
| OCR не видит надпись в перспективе (агент) | ограничение RapidOCR | контактный лист к каждому рендеру, смотреть глазами |
| под остановлен, кончился баланс (владелец) | бюджет не записан и не сверялся; веса на диске контейнера | `render.budget_problem`, `render.preflight`, веса на постоянном томе |
| графика «дёшево» (владелец, 10-08) | статичные PNG Pillow без движения и материала | `render_gfx.py`: HTML/CSS → VP9 с альфой; `edit.video_input` |
| реплики «кринж», нет боя и интриги (владелец, 10-08) | сценарий из гэгов «VPN против VPN» | сценарий v3; `validate.check_reveal` + `secret_words`: продукт не назван до развязки |
| нашивки дешёвые и нереалистичные (владелец, 10-08) | описание «dozens of patches» + шеврон-реф | `make_assets.kit_prints`: один печатный спонсор, как на форме UFC |
| водяной знак еле заметен (владелец, 10-08) | подпись в углу внутри общей графики | `Edit.watermark` + `edit --no-watermark` |

## 5. Что пока держится только на внимательности

* **Хук и интрига.** Правило «не раскрывать карты» в коде есть (`reveal_from`),
  а качество первых двух секунд машиной не меряется: его оценивает человек по
  пробному рендеру S01 (RUNBOOK, шаг 3).

* **Надписи на кадре.** OCR ловит только плоский текст, без перспективы, поэтому
  контактный лист смотрят глазами. Для массового контента нужна детекция
  надписей посильнее либо референсы каждой поверхности с текстом.
* **Разница в росте** задаётся числами и в тестах выполнена, но QA её не
  меряет.
* **Похожесть лиц на рефы** не меряется: в рабочем окружении нет InsightFace.
* **Звук:** объективные метрики (Whisper WER, всплески, флаттер) не отличили
  «глючный» звук от чистого. Причину нашли на слух владельца, а не прибором.
* **Бюджет заказа** не назван, `budget_usd = 0`, поэтому проверка бюджета
  выключена. Остаток баланса RunPod через MCP не читается.

## 6. Метрики, которые нужно собирать на каждом ролике

Все они уже пишутся в журнал. Для сравнения роликов не хватает только отзыва
`review` с `shot` и исходом при приёмке плана:

1. Попыток на принятый план, по постам камеры (`attempts` / `accepted`).
2. Причины брака QA (`qa_fail_reasons`), то есть какие правила срабатывают чаще всего.
3. GPU-секунд на секунду ролика и долю генерации в счёте провайдера.
4. Замечания владельца на ролик и сколько из них уже закрыты правилами.
